# Hanabi Action Space Interpretations
Each action code is an integer corresponding to an index in the action vector. 
Player +1 refers to the next player. Player +2 refers to the other player (the next next player)

| Action Type | Action Code | Description |
| :---: | :---: | :--- |
| **Discards (Your Hand)** | 0 | Discard card 0 |
| | 1 | Discard card 1 |
| | 2 | Discard card 2 |
| | 3 | Discard card 3 |
| | 4 | Discard card 4 |
| **Plays (Your Hand)** | 5 | Play card 0 |
| | 6 | Play card 1 |
| | 7 | Play card 2 |
| | 8 | Play card 3 |
| | 9 | Play card 4 |
| **Hints to Next Player ("Player +1")** | 10 | Reveal Red |
| | 11 | Reveal Yellow |
| | 12 | Reveal Green |
| | 13 | Reveal White |
| | 14 | Reveal Blue |
| | 15 | Reveal Rank 1 |
| | 16 | Reveal Rank 2 |
| | 17 | Reveal Rank 3 |
| | 18 | Reveal Rank 4 |
| | 19 | Reveal Rank 5 |
| **Hints to Other Player ("Player +2")** | 20 | Reveal Red |
| | 21 | Reveal Yellow |
| | 22 | Reveal Green |
| | 23 | Reveal White |
| | 24 | Reveal Blue |
| | 25 | Reveal Rank 1 |
| | 26 | Reveal Rank 2 |
| | 27 | Reveal Rank 3 |
| | 28 | Reveal Rank 4 |
| | 29 | Reveal Rank 5 |
